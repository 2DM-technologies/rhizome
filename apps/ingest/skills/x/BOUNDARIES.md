# X source boundaries

- All provider identifiers, record shapes, endpoints, scopes, and error interpretation stay under
  this directory.
- Archive and OAuth adapters normalize into the contracts at the package root and compile through
  the same eligibility, ordering, media-budget, VERIFY, and candidate-bundle implementation.
- The host and server may consume only generic manifests, preprocessing, connection, and
  `candidate_bundle@1` capabilities. They must never branch on an X source ID.
- Exact post text is stored once as the first text element. It is never copied into source
  properties or rewritten during URL-entity handling.
- Quote targets remain inert identifiers and URLs; this package does not create object
  relationships.
